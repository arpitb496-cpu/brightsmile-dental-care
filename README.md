# BrightSmile Dental Care — Jabalpur

Modern, responsive website for **BrightSmile Dental Care**, a premier dental clinic located in Wright Town, Jabalpur, Madhya Pradesh, India.

## 🦷 Highlights & Features
- **Modern Medical UI**: White, vibrant teal (`#0d9488`), and trust soft blue (`#0284c7`).
- **Comprehensive Clinical Services**: Teeth Cleaning, Invisible Braces & Aligners, Single-Sitting Painless RCT, Laser Whitening, Dental Implants, and Zirconia Crowns with direct booking integration.
- **Doctor Profile**: Dr. Ayush Sharma (BDS, MDS - Prosthodontics & Implantology) with credentials and sterilization protocols.
- **Localized Jabalpur Reviews**: Napier Town, Civil Lines, Vijay Nagar, Gorakhpur, and Wright Town testimonials.
- **Appointment Booking**: 10-digit Indian phone validation, date & time slot selection, Formspree AJAX submission, and instant confirmation modal.
- **Interactive Map & Clinic Timings**: Location card with directions and clinic hours.
- **Floating Controls**: Pulsing WhatsApp quick chat button and mobile-sticky action bar.
- **SEO & Schema**: LocalBusiness / Dentist `JSON-LD` structured data and OpenGraph tags.

## 🚀 Getting Started
Open `index.html` in any modern web browser or run a lightweight local server:
```bash
python3 -m http.server 3000
```
Then visit `http://localhost:3000`.
